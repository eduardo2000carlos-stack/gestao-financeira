# Carlos Eduardo – Gestão Financeira (V6)

Protótipo demonstrativo responsivo em HTML, CSS e JavaScript.

## Publicar no GitHub Pages
1. Envie `index.html` para a raiz do repositório.
2. Abra Settings > Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Selecione `main` e `/(root)`, depois Save.

Os dados são armazenados apenas no navegador (localStorage). Não há autenticação, banco de dados ou sincronização. Use somente dados fictícios nesta demonstração.
